Set up before you run

Four fields at the top of the dashboard — fill them once, then save them in a profile.

ADB DEVICEPlug the phone in with USB debugging on. It appears in the list; press ⟳ if it doesn't. The status bar at the bottom shows ADB health.
CALL NUMBERThe number of your helper phone — the phone that receives and places the test calls. 5–15 digits. Needed for every scenario except 6.
EVIDENCE ROOTThe folder where screenshots are saved. Use 📁 to browse. A green ✓ in the status bar means the folder exists and is writable.
CLEAR RECENT APPS AFTER RUNTidies the phone's recent apps once a run finishes successfully.
PROFILESThe profile menu (top right, e.g. “Work”) remembers call number, evidence root and the clear-recents choice. Save with Settings → Profiles.

The scenarios

Find a card with search, the All / Wi-Fi / Data / Combined filters or Sort. The 📄 button beside Run opens that scenario's evidence.

📞 Phone calls in 3+5+9B

This scenario places 3 calls to your helper phone (the CALL NUMBER). Here is exactly what to do — the console also shows a live banner and beeps at every step.

Keep the helper phone unlocked, ringer on, and within reach for the whole run. Other scenarios that place a test call show the same “Pick up the call” banner.

While a run is active

Everything updates live — you never have to guess what the console is doing.

Progress ring & stagesScreenshots taken out of the total, plus Pre-flight → Before update → Restart → Update complete → After update → Report.
Live screenThe latest screenshot from the phone, as it is captured.
Live log · Run stepsEvery action in real time (green = success, amber = warning, red = problem) and a tidy step timeline.
Evidence · Device infoBrowse saved screenshots and open their folder; see model, Android, build, patch level, carrier and battery.
Call bannerTells you when to answer, when to call back, and counts down the time you have.
■ StopEnds the run immediately. “Clear log” only empties the on-screen log.
